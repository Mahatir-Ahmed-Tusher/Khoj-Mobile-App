# Khoj (খোঁজ)

Khoj is a comprehensive, bilingual Android application designed to combat misinformation and empower users with accurate, verified information. Built with a focus on usability and reliability, Khoj serves as a dedicated platform for fact-checking news, claims, and media.

## Key Features

* **Bilingual Interface:** Fully supported in both Bengali and English, ensuring accessibility for a diverse user base.
* **Instant Claim Verification:** Users can submit statements, news excerpts, or rumors to receive a structured fact-checking report that includes clear verdicts.
* **Image and Photocard Analysis:** Users can extract text directly from images, screenshots, or photocards. The system intelligently identifies and preserves source attributions for accurate context during verification.
* **Khoj Chat:** An interactive conversational interface that allows users to ask questions, explore topics, and verify information in real-time.
* **Liberation War Corner (মুক্তিযুদ্ধ কর্নার):** A specialized, dedicated section providing authentic and reliable historical information regarding the Liberation War of Bangladesh.
* **History and Tracking:** Users can keep a personal log of previously fact-checked claims and access past reports at any time.
* **Clean & Modern UI:** Designed with a premium, glassmorphic aesthetic to provide a highly readable and engaging user experience.
